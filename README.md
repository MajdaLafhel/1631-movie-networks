This repository hosts the **1631 Movie Character Networks** dataset, a large-scale dataset for character networks.

---

## 📂 Repository Structure

As shown in the repository interface:
* `1631 movie networks.zip`: Contains the complete dataset consisting of 1,631 character networks.
* `README.md`: Project documentation and citation details.
